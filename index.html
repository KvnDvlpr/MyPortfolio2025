Daywell

A planner for work, studies, and your walk with God.

Live

Full-stack daily planner: auth, tasks that repeat on their own, a focus timer, a calendar, a verse of the day, and daily progress. I built the whole thing, from the Postgres schema and row-level security to the shadcn design system and the test suite.

What it does

  • Supabase Auth with email confirmation
  • Repeating tasks with a focus countdown
  • Calendar with events and an upcoming list
  • Verse of the day, rotating by day of year
  • Row-level security per user

How it's built

  • Next.js 16 App Router + server actions
  • TypeScript, React 19, TanStack Query
  • Tailwind v4 + shadcn/ui
  • react-hook-form + zod validation
  • Vitest unit tests, Playwright E2E
